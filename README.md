Bloomora - Flower Shop E-commerce Platform

Bloomora is a full-stack e-commerce web application designed for a flower shop. It features a dynamic user interface and a robust administrative dashboard for inventory and user management.

🚀 Key Features

User Interface (Frontend):
     Dynamic Product Listing: Flowers are fetched in real-time from a Spring Boot API.
     Shopping Cart: Add flowers to the cart, manage quantities, and calculate totals using localStorage.
     User Authentication: Registration and Login functionality with database persistence.

Admin Dashboard:

     Product Management (CRUD): Add, update, and delete flower products.
     User Management: View registered customers directly from the database.
     Business Stats: Real-time counters for total users and products.

🛠️ Tech Stack

Frontend: HTML5, CSS3, JavaScript (ES6+), FontAwesome Icons.
Backend: Spring Boot (Java), Spring Data JPA.
Database: MySQL.
Tools: XAMPP (for MySQL server), VS Code / Spring Tool Suite (STS     

📋 Installation & Setup

1. Clone the Repository: https://github.com/harshaniwijayarathne/Flower-shop--e-commerce
2. Database Configuration:
      Open XAMPP and start Apache and MySQL.
      Go to phpMyAdmin and create a database named bloomora.
      The tables will be automatically generated by Spring Boot, or you can use the SQL scripts provided in the /database folder.
3. Backend Setup:
      Open the backend project in STS or IntelliJ.
      Update application.properties with your MySQL username and password.
      Run the application as a Spring Boot App.
4. Frontend Setup: Open index.html in any modern web browser.
